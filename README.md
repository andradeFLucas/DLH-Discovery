## 🌟 Visão Geral & Proposta de Valor

No setor automotivo, **milhões de reais são perdidos todos os meses** em gargalos invisíveis na ponta da operação: follow-ups lentos com frotistas, ociosidade em boxes de oficina, perda de leads de seminovos e atritos de comunicação entre departamentos.

O **Dealer Hub (Embaixadores de IA)** é a primeira plataforma desenhada especificamente para **capturar, estruturar e prototipar ideias inovadoras** vindas de quem mais entende dos problemas: a equipe que está no chão de fábrica e no showroom.

> **Do problema ao protótipo executivo em menos de 2 minutos:**  
> O colaborador relata uma dor da sua rotina operacional e um esquadrão de agentes de Inteligência Artificial gera instantaneamente **uma aplicação interativa pronta para teste**, **um documento técnico de engenharia (PRD)** e **uma apresentação comercial (Pitch Deck) com cálculo de ROI** para a diretoria.

## 💼 Os 3 Pilares de Entrega Instantânea

Ao submeter qualquer ideia ou desafio operacional, a plataforma orquestra um pipeline de IA que entrega **3 ativos estratégicos complementares**:

```
                              ┌────────────────────────────────────────┐
                              │     ENTRADA: DESAFIO OPERACIONAL       │
                              │ (Vendas, Oficina, F&I, Peças, CRM)     │
                              └──────────────────┬─────────────────────┘
                                                 │
                                                 ▼
                              ┌────────────────────────────────────────┐
                              │  AGENTE 0: ORQUESTRADOR MASTER         │
                              │  (Análise de Contexto & Blueprint)     │
                              └──────────────────┬─────────────────────┘
                                                 │
                   ┌─────────────────────────────┼─────────────────────────────┐
                   │                             │                             │
                   ▼                             ▼                             ▼
   ┌──────────────────────────────┐ ┌──────────────────────────────┐ ┌──────────────────────────────┐
   │ 📱 1. PROTÓTIPO INTERATIVO  │ │ 📋 2. PRD & ARQUITETURA TI   │ │ 💼 3. PITCH DECK DE NEGÓCIOS │
   │  Interface funcional ao vivo │ │  Requisitos, APIs e Banco SQL│ │  Slides, ROI e Justificativa│
   │  para validação com usuários │ │  para o time de tecnologia   │ │  para aprovação da Diretoria│
   └──────────────────────────────┘ └──────────────────────────────┘ └──────────────────────────────┘
```

### 1. 📱 Protótipo Interativo Funcional (UX/UI ao Vivo)
- Aplicação web interativa em tempo real (HTML5/Tailwind) rodando dentro da plataforma.
- Permite que gerentes e diretores **testem a experiência prática da solução**, cliquem em botões, adicionem dados e visualizem fluxos antes de investir 1 real em desenvolvimento.

### 2. 📋 Documento de Requisitos de Produto (PRD de Engenharia)
- Especificação técnica completa para o time interno de TI ou software houses parceiras.
- Inclui modelagem de tabelas de banco de dados (PostgreSQL/Supabase), contratos de API RESTful, diagrama de fluxo operacional e análise de viabilidade técnica.

### 3. 💼 Pitch Deck Comercial com Projeção de ROI
- Apresentação executiva em formato de slides com design corporativo de alto impacto.
- Mapeamento da dor, personas atendidas, projeção de tempo poupado por dia, estimativa de aumento de conversão/faturamento e estratégia de mitigação de riscos para aprovação em comitês.

## 🧠 Arquitetura Inteligente de Multi-Agentes

Por trás da interface simples e intuitiva, opera um pipeline de alta tecnologia:

1. **Discovery Guiado (16 Questões Estruturadas):** Extrai a essência do problema (volume, perdas financeiras, personas, sistemas legados, frequência).
2. **Orquestrador Master (Claude 3.5 Sonnet):** Atua como o Arquiteto e Estrategista-Chefe, categorizando o domínio do negócio e gerando o *Master Blueprint*.
3. **Esquadrão Especialista Paralelo (Claude 3.5 Haiku):**
   * *Agente UI/UX:* Constrói a interface e lógica interativa.
   * *Agente de Engenharia:* Modela arquitetura, banco de dados e APIs.
   * *Agente de Negócios:* Desenvolve o pitch executivo com cálculos de ROI.
4. **Fallback Inteligente de Alta Fidelidade:** Garante disponibilidade contínua com geração contextual mesmo em instabilidades de rede externa.

## 🚀 Como Começar / Demonstração Rápida

### Pré-requisitos
* Node.js 18+ instalado
* Navegador moderno (Chrome, Edge, Safari, Firefox)

### Executando em Ambiente Local

1. **Clonar e instalar dependências:**
   ```bash
   npm install
   ```

2. **Configurar variáveis de ambiente (Opcional para IA ao vivo):**
   Crie um arquivo `.env.local` na raiz:
   ```env
   ANTHROPIC_API_KEY=sua_chave_anthropic_aqui
   ```
   *(Caso não possua chave configurada, a plataforma utiliza o motor inteligente de fallback para demonstração imediata).*

3. **Iniciar a aplicação:**
   ```bash
   npm run dev
   ```
   Abra no seu navegador: **`http://localhost:3000`**

## 🔒 Segurança, Governança e Privacidade

- **Arquitetura Segura:** Nenhum dado sensível de clientes finais (como CPF, dados bancários ou chassis) precisa ser exposto durante a fase de discovery e ideação.
- **Isolamento de Negócio:** Modelado para operação multi-tenant, permitindo segregação por concessionária, marca ou regional.
- **Preparado para Integração:** Pronto para conectar com os principais DMS e ERPs do mercado automotivo (Linx, NBS, Apollo, Dealernet, Sisdia, TOTVS).
